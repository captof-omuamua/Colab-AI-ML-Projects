# Indic Speech-Recognition Variants

Further Tamil and Hindi speech-recognition experiments that sit alongside the main [speech notebooks](../README.md).

| Notebook | What it covers |
| --- | --- |
| [WAV2VEC-TAMIL-FINETUNED-1.ipynb](WAV2VEC-TAMIL-FINETUNED-1.ipynb) | Tamil Wav2Vec 2.0 fine-tuning with CTC loss. |
| [wav2vec.ipynb](wav2vec.ipynb) | A second Wav2Vec 2.0 experiment with a different configuration. |
| [whisper-tamil-experiment-1.ipynb](whisper-tamil-experiment-1.ipynb) | Tamil Whisper fine-tuning experiment. |
| [xls_r_fine_tuning.ipynb](xls_r_fine_tuning.ipynb) | XLS-R fine-tuning setup, related to the Hindi XLS-R notebook in the main collection. |

The Whisper fine-tuning notebook used in the [Tamil-to-Telugu speech translation](https://github.com/captof-omuamua/Ensemble-Transformer-Model-for-Speech-to-Speech-Translation-Tamil-to-Telugu-) project is kept in that repository.

Set the dataset and model paths, language, and any access tokens (as environment variables) before running. Datasets, audio and checkpoints are not stored in the repository.
