# Additional Indic speech-recognition variants

Recovered semester notebooks are grouped here with the existing speech collection rather than published as another overlapping repository.

| Notebook | Recovered material |
| --- | --- |
| [WAV2VEC-TAMIL-FINETUNED-1.ipynb](WAV2VEC-TAMIL-FINETUNED-1.ipynb) | Tamil Wav2Vec/CTC fine-tuning variant. |
| [wav2vec.ipynb](wav2vec.ipynb) | Additional Wav2Vec experiment with different configuration. |
| [whisper-tamil-experiment-1.ipynb](whisper-tamil-experiment-1.ipynb) | Tamil Whisper experiment variant. |
| [xls_r_fine_tuning.ipynb](xls_r_fine_tuning.ipynb) | Historical XLS-R fine-tuning configuration, closely related to the existing Hindi notebook. |

Two semester Whisper files had identical code; only one is retained here. The recovered `whisper_fine_tuning.ipynb` has the same code as the existing translation repository's notebook and is also closely aligned with the collection's Malayalam Whisper notebook; another copy is unnecessary.

Notebook outputs, execution counts, embedded tokens, and team identifiers were cleared in these publication copies. These are historical variants; no new ASR score is claimed. Review dataset/model paths, language selection, access requirements, and package versions before running. Datasets, private audio, and checkpoints are supplied separately.
