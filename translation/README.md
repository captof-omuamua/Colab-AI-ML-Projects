## Running these notebooks

PyTorch, Transformers and the IndicTrans tokenizer/toolkit used by the selected notebook. Model downloads and local input files are configured in the cells.

Open one notebook in Colab or Jupyter, read its setup cells, set the input paths, and then run the sections you need. Training and network operations are not run automatically by this repository.

The notebooks adapt AI4Bharat's IndicTrans2 inference examples. See the [upstream project](https://github.com/AI4Bharat/IndicTrans2) for the models and their terms.
